# Six-image studio-edit pilot — approval gate

Six original photographs were edited through six separate built-in image editing calls. Targets: A027 T-shirt, A049 rugby top, A046 zip hoodie, A055 cropped wide-leg bottoms, A104 women’s striped hoodie, A195 children’s ROSES T-shirt. All proposals are1086×1448. Originals are retained with source IDs, filenames/decks/slides, checksums and prompts in the private review gallery. No proposal or bulk derivative is integrated into this branch.

The intended edit is a consistent neutral warm-grey studio backdrop, clean separation, soft realistic shadows and balanced lighting while retaining actual silhouette, colours, artwork, seam/collar/cuff construction, labels and fabric appearance. Source-preserving original pixels are preferable wherever the model reconstructs garment details.
